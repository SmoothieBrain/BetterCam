# BetterCam

This is a Post Processing camera mod for A Township Tale

# Usage
Simply find the camera logo in your radial menu and either choose ON or the settings.

# Current effects we have

- Post exposure
- Contrast
- Saturation
- Temperature
- Tint
- Hue
- Filter
- Bloom
- Vignette
- Grain
- Chromatic Abberation
- Distortion
- BlurredCorners
